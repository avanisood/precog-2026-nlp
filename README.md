# AI Text Detection: Human vs AI Victorian Literature

A comprehensive system to detect and analyze linguistic differences between human-written Victorian literature and AI-generated text, including rigorous adversarial testing and explainable AI analysis.

This was completed as part of the Precog@IIIT-H recruitment assignment. The task document can be found in `notebooks/Precog Task Document 2026 (1).pdf`.

## Tasks Overview

0. **[Dataset Preparation](data/)** - Dataset creation and preprocessing
1. **[Task 1: The Fingerprint](notebooks/Task1_The_Fingerprint_EDA_COMPLETE.ipynb)** - Statistical proof of mathematical distinction between classes
2. **[Task 2: Multi-Tiered Classification](notebooks/)** - Three-tier detection system
   - [Tier A: The Statistician](notebooks/Task2_1_Tier_A_The_Statistician.ipynb) - XGBoost with hand-crafted features
   - [Tier B: The Semanticist](notebooks/Task2_2_Tier_B_The_Semanticist.ipynb) - GloVe embeddings + Neural Network
   - [Tier C: The Transformer](notebooks/Task2_3_Tier_C_The_Transformer.ipynb) - DistilBERT + LoRA fine-tuning
3. **[Task 3: The Smoking Gun](notebooks/Task3_The_Smoking_Gun_XAI_actual.ipynb)** - Captum-based explainability analysis
4. **[Task 4: The Turing Test](notebooks/Task4_Genetic_Algorithm.ipynb)** - Genetic algorithm adversarial testing

I have completed **all tasks**, with detailed analysis and implementation decisions documented in notebook markdown blocks.

**My main contribution** is the discovery of a **critical security vulnerability** in Task 4: the detector can be trivially bypassed (96.99% success rate) via simple prompt engineering in ~60 seconds, requiring only beginner-level skills. This reveals that the model learned the PRESENCE of Victorian markers rather than their NATURALNESS, making it unsuitable for production deployment without adversarial hardening.

## Dataset Classes

All datasets are located in the `data/` folder:

- **Class 1 (Human)**: `precog.csv` - 973 paragraphs from authentic Victorian literature (Arthur Conan Doyle, P.G. Wodehouse, Mark Twain, William Shakespeare)
- **Class 2 (AI Vanilla)**: `class_2_pro_vanilla_combined.csv` - 500 paragraphs generated by Gemini without specific style prompts
- **Class 3 (AI Mimicry)**: `class_3_pro_combined.csv` - 1000 paragraphs generated by Gemini with explicit prompts to mimic Victorian authors (Doyle, Stevenson)

## Methods & Tools

- **Statistical Analysis**: T-tests, Mann-Whitney U, Cohen's d effect sizes (Task 1)
- **Lexical Features**: Type-Token Ratio (TTR) variance, Hapax Legomena, Zipf analysis (Task 1)
- **Syntactic Analysis**: SpaCy for POS tagging and dependency parsing (Task 1)
- **Traditional ML**: XGBoost with hand-crafted features (Task 2.1)
- **Neural Networks**: GloVe embeddings + feedforward network (Task 2.2)
- **Transformers**: DistilBERT + LoRA parameter-efficient fine-tuning (Task 2.3)
- **Explainable AI**: Captum LayerIntegratedGradients for attribution analysis (Task 3)
- **Adversarial Testing**: Genetic algorithms with fitness-based evolution (Task 4)

### Key Libraries Used:
- `transformers` (Hugging Face) - DistilBERT model
- `peft` - LoRA adapters
- `captum` - Attribution methods
- `xgboost` - Gradient boosting
- `spacy` - NLP preprocessing
- `scikit-learn` - ML utilities
- `google-generativeai` - Gemini API for data generation and mutations
